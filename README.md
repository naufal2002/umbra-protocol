Umbra Protocol — a top-down 2D stealth game built in pure vanilla TypeScript/JavaScript and HTML5 Canvas, no external libraries, no build step, no network requests. Sneak past patrolling guards and their vision cones, use cover to break line of sight, and reach the exit before your alert meter fills.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with WASD.
